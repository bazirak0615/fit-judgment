## 1. 프로젝트 한 줄 요약

> JD와 후보자 이력서의 적합도를 **차원별 정량 점수 + 근거 narrative + 면접 질문 가이드 + PDF 보고서**로 자동 산출하는 채용 의사결정 보조 도구. 로컬 LLM (Ollama) 또는 클라우드 API (향후) 어느 쪽에서도 동작.

## 3. 핵심 가치 명제

### 1차 가치 — 운영용
- **일관성**: 평가자별 편차 제거, 동일 기준·가중치로 100% 결정적 결과
- **속도**: 13명 일괄 평가 5분 (API 백엔드) / 0.5초 (Mock 데모)
- **풍부도**: 단순 점수가 아닌 차원별 매칭/부족/근거 + 면접 질문 + PDF

### 2차 가치 — 포트폴리오용 (V2 신설)
- **확장성 시연**: LLM 백엔드 추상화 — 환경변수 한 줄로 mock/ollama/api 전환
- **즉시 체험 가능**: API 키 없이도 Mock 모드로 깃헙 클론자가 5분 내 전체 흐름 시연 가능

### 명시적 비목표
- 1초 즉답 챗봇 ❌ (구조화된 평가가 핵심)
- 후보자 자동 채용/탈락 결정 ❌ (보조 도구일 뿐)
- 인사 데이터 외부 클라우드 자동 전송 ❌ (로컬 우선)

## 7. 평가 모델

### 5개 기본 차원

| 차원 | 분류 | 기본 가중치 | 평가 대상 | JD 매핑 |
|---|---|---|---|---|
| Hard Skills | 필수 | 30% | JD 명시 자격·스킬 보유 여부 | `must_have` |
| Experience | 필수 | 25% | JD 요구 업무를 실제 수행 경험 | `key_responsibilities` |
| Achievements | 필수 | 20% | JD 강조·암시 성과 신호 | `emphasis_keywords`, `hidden_criteria` |
| Domain Fit | 우대 | 15% | 산업/도메인 매칭 | `domain`, `nice_to_have` |
| Seniority | 우대 | 10% | 연차·역할 레벨 | `seniority_level` |

### 제약
- 필수 합계 ≥ 50%
- 우대 합계 ≤ 50%
- 전체 = 100%
- 사용자 차원 추가/삭제 가능

### 하드 게이트
- 필수 항목 최저 점수 (기본 50점)
- 정보 미기재 시 등급 1단계 하향
- 회피 키워드 (단기 이직, 6개월 이하 등)

## 8. Mock 데이터 시나리오 (V2)

3개 JD × 12명 후보자 = 12개 사전 평가 (다른 조합은 휴리스틱 fallback)

| JD | 후보자 풀 (이상 매칭) | 점수 분포 (예시) |
|---|---|---|
| 교육사업팀장 (EduGrowth) | c01, c02, c03, c04 | 86 / 62 / 28 / 92 |
| 시니어 데이터 엔지니어 (DataPlex) | c05, c06, c07, c08 | 90 / 50 / 95 / 25 |
| 그로스 마케터 (SaaSlift) | c09, c10, c11, c12 | 89 / 65 / 30 / 96 |

각 평가에는 다음이 포함됨:
- 차원별 점수·매칭/부족 항목·근거 인용
- 검증 포인트 (3~5개)
- 강점 / 리스크
- 면접 질문 자동 생성 (5~10개)

## 12. 16번 프로젝트와의 연관

본 도구는 16번 JD 생성기와 한 사이클로 동작:

```
[16번 JD 생성기]                 [17번 적합인재 판단기]
회사명 → 자동 정보 수집  →     생성된 JD + 후보자 이력서
        → 5분 내 JD 생성              → 5분 내 N명 적합도 평가
                                       → 1순위 추천 + 면접 질문 + PDF
```

채용 프로세스의 **JD 작성 → 후보자 스크리닝**까지 end-to-end 자동화.

V3-6에서 두 도구의 자동 연동 (생성된 JD를 본 도구로 직접 import) 예정.

## 13. V1 → V2 진화 시사점

| 패턴 | V1 (운영용 MVP) | V2 (포트폴리오/확장 가능) |
|---|---|---|
| LLM 의존 | 단일 (Ollama 하드코딩) | 추상화 + 백엔드 3종 분기 |
| 데모 가능성 | 사용자 PC + 모델 다운로드 필요 | 깃헙 클론 → `LLM_BACKEND=mock` 즉시 실행 |
| 보고서 형태 | 화면 + JSON | + PDF + 차트 + narrative + 면접 질문 |
| 이력 관리 | 평탄한 표 | JD별 그룹 + 검색·필터 + 다운로드 |
| 데이터 영속성 | session_state (휘발) | + 디스크 자동 저장 + 5중 안전망 |
| 사용자 정의 시각화 | 표만 | 레이더 + 막대 + 랭킹 차트 |

V1 → V2 전환에 약 1.5일 (사용자 8시간 + AI 백그라운드 8시간) 소요.
