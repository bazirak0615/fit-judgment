# 그로스 마케터 (Performance + Lifecycle) 채용

## 회사 소개
SaaSlift Inc.는 B2B SaaS 협업 도구 (10인~500인 규모 기업 대상)를 제공합니다.
누적 가입 5만 사, MAU 80만, 연 매출 200억 규모이며 PLG(Product-Led Growth) 모델로 성장 중입니다.

## 역할 한 줄 요약
신규 가입(Acquisition) 부터 활성화·전환·확장(AAARR 전체 퍼널)까지 데이터 기반으로 운영하며,
유료 광고 + 라이프사이클 마케팅 + A/B 실험을 통합 책임지는 그로스 마케터를 찾습니다.

## 이런 일을 하게 돼요

### 유료 광고 운영
- Google / Meta / LinkedIn / Naver 광고 채널 직접 집행
- 월 광고비 5천만원 → 1.5억원으로 확대 책임
- ROAS / CAC / LTV 기반 채널·캠페인 최적화

### 라이프사이클 마케팅
- 가입 → 활성화 → 유료 전환 → 재구매 단계별 메일·인앱 메시지·리타게팅 설계
- Braze / Customer.io 같은 마케팅 자동화 도구 운영
- 코호트별 리텐션 분석 + 이탈 방지 캠페인

### 그로스 실험 (A/B 테스트)
- 가설 수립 → 실험 설계 → 결과 분석 → 학습 문서화
- 월 5~10건 실험, 분기당 유의미 1~3건 발굴
- VWO / Optimizely 또는 자체 실험 플랫폼 운영

### 데이터 분석·리포팅
- SQL 직접 쿼리 + Tableau/Looker 대시보드 제작
- 주간 그로스 리포트 (CEO·VP에게 보고)
- 가입 펀넬 attribution 분석

### 크로스팀 협업
- 프로덕트팀: 활성화 개선 실험 협업
- 세일즈팀: MQL → SQL 전환 최적화
- 콘텐츠팀: SEO/블로그 트래픽 → 가입 전환 분석

## 이런 분을 찾고 있어요

- 디지털 마케팅 또는 그로스 5년 이상 경력
- 유료 광고 직접 집행 (월 5천만원 이상 운영) 경험 2년 이상 필수
- SQL 직접 쿼리 가능 (BI 분석가 도움 없이 대시보드 제작 가능)
- A/B 테스트 설계·해석 경험
- B2B SaaS 또는 PLG 모델 경험 우대

| 역량 | 기준 |
| --- | --- |
| 퍼포먼스 마케팅 | Google/Meta/LinkedIn 채널에서 캠페인 직접 운영, ROAS 개선 사례 보유 |
| 라이프사이클 | 사용자 라이프사이클별 메시지·캠페인 설계·운영 |
| 분석력 | SQL + 코호트 분석 + 어트리뷰션 모델 이해 |
| 실험 | A/B 테스트 가설 수립부터 결과 해석까지 직접 수행 |
| 도구 | Braze, Customer.io, Mixpanel, Amplitude 등 마케팅·분석 도구 운영 경험 |

## 이런 분이라면 더 좋아요

- B2B SaaS 도메인 경험 (PLG 모델 우대)
- HubSpot / Marketo / Pardot 등 MA 도구 admin 경험
- Python으로 데이터 분석 자동화 가능
- 영어 비즈니스 회화 (글로벌 캠페인 협업)
- Series B 이후 스타트업에서 그로스 팀 빌딩 경험

## 이런 분과 맞지 않습니다
- 콘텐츠 마케팅·브랜딩 위주 경력 (퍼포먼스 광고 직접 집행 경험 없음)
- 광고 대행사 출신만 있고 인하우스 운영 경험 없는 분
- SQL 안 다루는 분
