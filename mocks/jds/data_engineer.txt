# 시니어 데이터 엔지니어 채용

## 회사 소개
DataPlex Inc.는 전자상거래·금융 도메인의 대규모 이벤트 데이터 파이프라인을 운영하는 데이터 인프라 회사입니다.
일 평균 50억 건의 이벤트를 수집·가공·서빙하며, 100여 개 사 고객사에 데이터 제품을 제공합니다.

## 역할 한 줄 요약
배치·스트리밍 파이프라인을 안정 운영하면서 신규 데이터 제품(Feature Store, 실시간 KPI 대시보드)을
End-to-End로 설계·구현하는 시니어 데이터 엔지니어를 찾습니다.

## 이런 일을 하게 돼요

### 데이터 파이프라인 설계·운영
- Spark / Airflow 기반 일 50억 건 이벤트 ETL 파이프라인 운영
- Kafka 기반 실시간 스트리밍 파이프라인 (Flink, Kafka Streams) 신규 구축
- 파이프라인 성능 튜닝, 비용 최적화 (현재 월 AWS $80K → 30% 절감 목표)

### 신규 데이터 제품 개발
- Feature Store(Feast/Tecton) 도입 및 ML 팀 협업
- 실시간 KPI 대시보드 백엔드 (ClickHouse / Pinot)
- 고객사용 Data API (REST/GraphQL) 설계·구현

### 데이터 품질·신뢰성
- dbt 기반 데이터 모델링 + 데이터 품질 테스트
- 모니터링·알람 (Datadog, PagerDuty) 운영
- SLA 99.9% 달성

### 기술 리더십
- 주니어 2~3명 멘토링
- 코드 리뷰, 아키텍처 결정 주도
- 기술 부채 우선순위 관리

## 이런 분을 찾고 있어요

- 데이터 엔지니어링 6년 이상 (백엔드 개발 포함 가능)
- Spark / Hadoop 등 분산 처리 프레임워크 운영 경험 3년 이상 필수
- Python + SQL 능숙
- AWS / GCP 등 클라우드 환경에서의 데이터 인프라 구축 경험
- Airflow 또는 유사 워크플로우 오케스트레이션 운영 경험

| 역량 | 기준 |
| --- | --- |
| 분산 처리 | 일 1억 건 이상 데이터 처리 파이프라인을 직접 설계·운영한 경험 |
| 스트리밍 | Kafka/Flink/Kinesis 등 실시간 파이프라인 운영 경험 (1년 이상) |
| 데이터 모델링 | dbt 또는 유사 도구로 데이터 마트 구축 경험 |
| 클라우드 인프라 | AWS EMR/Glue/Athena 또는 GCP Dataflow/BigQuery 운영 경험 |
| 협업 | 데이터 사이언스·BI·프로덕트 팀과 협업해 데이터 제품 출시 경험 |

## 이런 분이라면 더 좋아요

- 핀테크 / 이커머스 도메인 경험
- Feature Store 또는 ML 인프라 구축 경험
- IaC (Terraform) 운영 경험
- Open source 기여 또는 컨퍼런스 발표 경험
- 영어 비즈니스 회화 가능 (글로벌 본사 협업)
- 비용 최적화로 인프라 비용 30%+ 절감해본 경험

## 이런 분과 맞지 않습니다
- 분석·BI 위주 경력 (데이터 인프라 직접 구축 경험 없음)
- 단일 시스템·단일 회사에서만 일해본 분 (다양한 환경 경험 선호)
- 안정된 운영만 선호하고 신규 제품 개발에 관심 없는 분
